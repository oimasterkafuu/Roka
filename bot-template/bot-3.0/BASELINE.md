# Bot(3.0) 当前基线（第 15–16 轮后）

本文件记录 `feat/bot-3.0-1v1` 主线合入第 15–16 轮多线层之后的小图 1v1 验收数据。评测使用正式
`GameEngine`（`dist/` 构建产物）与上游最新 relay-bot 作为对手。

- 策略源码哈希（含 `mshape.js`/`mhalf.js`）：`02bbd803679d11c534d91ca5c48efba9101f87f9648dfe5102fcf537b594f2dc`
- 引擎基线：上游 `6821598 merge: disable multiline burst growth`
- 地图：官方小图（1v1 `0.34`），随机 / 迷宫 / 群岛 / 地中海
- 模式：迷雾关/开 × 多线关/开
- 对手：Apex / Anti-Human / Bot(2.0) / Relay（原版 relay-bot）
- 每个项目 32 局 = 16 个种子（`bot3-baseline-1` 至 `bot3-baseline-16`）× 双方换边
- 每局上限 1000 Tick；胜 = 对手先被淘汰，负 = Bot(3.0) 先被淘汰，超时 = 双方均存活至 1000 Tick
- 默认配置（无环境变量），`WORKERS=6` 前台跑完 16 个种子

合计 **2048 局：1702 胜 / 290 负 / 56 超时，胜率 83.1%**（较上一版 1688/299/61 提升 **+14 胜**，
逐格零退化；相对第 13 轮基线的翻转：11 败转胜、7 超时转胜、4 胜转败、5 负转超时、3 超时转负）。

## 验收状态

验收目标：对阵原版 Relay 的每个项目胜率 >= 65%；其余项目 >= 50% 且相对上一版不退化。

- 非 Relay 三对手：**全部 >= 50%，64 格中 0 个低于上一版基线**（唯一变动是 `anti/archipelago/fog+multi`
  29→30 胜）。
- Relay：**9 / 16 格达标** —— 8 个单线格 65.6%–71.9%，多线 `random` 明牌 65.6%（21/32）。

多线 8 格合计 **136/256（53.1%）**。第 15–16 轮把它从 123 拉到 136（+13 胜），并在全量矩阵上
零退化；剩余目标是每格 >= 65%（21/32），即还需 +32 胜。多线房间仍是**完美镜像**（两边同策，每个
种子严格 1 胜 1 负），因此只有**有偏**的策略（两席都赢）才能过线；第 15–16 轮的 9 条实验与负结果见
[ROUND16-ROUNDUP.md](ROUND16-ROUNDUP.md)，镜像证明见 [MULTI.md](MULTI.md)。

## 默认开启的层（第 15–16 轮新增）

| 层 | 作用 | 关闭方式 |
| --- | --- | --- |
| `mshape.js` 扩张形状层 | 脉冲 Tick 放开继承的 16 单上限（非脉冲 Tick 候选本来就少）；把「会废掉一次占领的合并」压到占领之后；领先 110% 或走廊房间退场 | `BOT3_MSHAPE=0` |
| `mhalf.js` 持续施压层 | 按我方领土到前线环的跳数场重排自己的合并：把「补满一个本 Tick 无法出兵、补后达到 3 兵（全冲推出的下限）」的合并排到最前；补不满的合并压到占领之下 | `BOT3_MHALF=0` |

`mshape.js` 的实测默认值为 `BOT3_MSHAPE_SLOTS=64`、`BOT3_MSHAPE_STEAL=100`、`BOT3_MSHAPE_LEAD=110`；
其余子开关（`CAPTURE`/`RING`/`FEED`/`FAN`/`HOLE`/`WATER`/`FRONTIER` 等）实测为零或负，保持 0。

## 大图零退化烟测

大图不在验收矩阵内。第 15–16 轮的默认层都带多线房间门控且只改多线候选评分，单线与大图路径不变；
本轮的 2048 局矩阵中 32 个单线格全部 0.0pp 逐局相同，即为零退化的直接证据。历史大图烟测见
`NEXT.md`。
