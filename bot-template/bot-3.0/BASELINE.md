# Bot(3.0) 首轮基线

首个提交的 Bot(3.0) 是 Relay 2.16.0 策略的完整副本（源提交 `4fb119a`）。本文件记录迁移到 `bot-template/bot-3.0/` 后的验收基线，作为后续小图 1v1 改进的对照。策略文件哈希 `39fd754753d72111f0f1f0f5d048eda16d0dd7809929a3a27576dcfc657b8e3d`。

## 方法

- 使用正式 `GameEngine`（`dist/` 构建产物），1v1 标准小图，双方地图比例 `0.34`。
- 对手只通过各自的公开托管入口加载：Apex、Anti-Human、Bot(2.0)、Relay。
- 四种地图：随机、迷宫、群岛、地中海；迷雾关/开；多线关/开。
- 每个项目 32 局 = 16 个种子（`bot3-baseline-1` 至 `bot3-baseline-16`）× 双方换边。
- 每局上限 1000 Tick。胜 = 对手先被淘汰；负 = Bot(3.0) 先被淘汰；超时 = 双方均存活至 1000 Tick。
- 每 Tick 推进 500 毫秒模拟时钟；对手的运行时随机性与决策耗时可能造成逐局波动。
- 16 个种子分四批运行，每批 4 个 worker，命令见 [README](README.md#评测)。

合计 2048 局：**1490 胜 / 424 负 / 134 超时，胜率 72.8%**（胜率分母包含超时）。

## 后续改进方向

- **全图单线**是最弱模式（56.6%）。随机图对 Anti-Human 仅 25.0%，地中海对 Anti-Human 31.3%；迷雾单线（61.1%）的超时明显更高，说明收尾与终结能力比开局更值得优先处理。
- **多线**已经接近饱和（全图 86.1%、迷雾 87.1%），除镜像外几乎全胜；后续改动应把预算集中在单线，不要回退多线。
- 随机与地中海单线的低分集中在 Anti-Human；迷宫单线对 Bot(2.0) 也只有 43.8%（14/18/0），可作为第二个诊断样本。
- 镜像局（Relay）只用于对称性检查；真正的小图 1v1 提升应按非镜像对手的胜负与超时变化衡量，并保持 2048 局矩阵不变以便配对比较。
