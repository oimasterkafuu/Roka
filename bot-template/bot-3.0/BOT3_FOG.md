# 迷雾单线层实验记录（Bot(3.0) 小图 1v1）

本文件记录 Bot(3.0) 针对迷雾小图单线格（`MODES=010`）的策略层：动机、实现、开关与配对评测结果。基线见 [BASELINE.md](BASELINE.md)，迷宫层见 [BOT3_MAZE.md](BOT3_MAZE.md)。

## 问题定位

迷雾的视野是切比雪夫半径 1，**视野来自己方领土而不是部队**，因此“派侦察兵”本身不提供任何情报：占领一格才是侦察，而单线每 Tick 只能出一条指令。`planner.js` 却按“看得见的目标”给每一帧定价，回放里能看到三处结构性失效：

1. **没有目标**。`targets` 来自记忆中的敌方皇冠，而敌方皇冠只有在我们的地皮贴到它邻格后才会被记住。`relay/random/seed 12` 1000 Tick 内一个敌方皇冠都没记住，`goal` 始终是无穷大，所有推进规则失效，规划器退化成侦察场。
2. **柱状主力不转化为进攻**。没有目标时行军项（`60 + sqrt(mass)`，踩自己格子还有最多 55 的收兵奖励）压过一切普通占领（`32..65`），1900 兵的主力整局在自己格子之间倒兵：同一局 255 个 Tick 里 194 个 Tick 用于自己合兵，41 个用于占中立，16 个用于进攻。
3. **未知格免费**。`assaultStrength` 只给可见守军定价，迷雾格上报 `grid_type 200 / army_cnt 0`，一条通向黑暗的路看起来免费。

迷雾档位还永久关闭了 `single` 分支（`single = clearSerial && ...`），所以迷宫层与收尾柱在这类格子里根本不会介入，等同于“通用路径 + 盲目”。

## 实现

新增 [fog.js](fog.js)，`planner.js` 加钩子。

### 第一层：柱状推进与前线瞄准（第二轮）

| 位置 | 内容 |
| ---- | ---- |
| `chooseOrders` 房间门控 | `fogOpen = !clearSerial && !multi && !maze && size <= maxBoard && turn >= startTurn` |
| 目标场 | `fogAim` 时把 `objectives` 回退到可见敌人；要求无记忆皇冠、非迷宫、且 `army * 100 >= enemyArmy * aimLead` |
| 材料门控 | `fogUpdate()` 在 `army >= enemyArmy * floor`、无敌方威胁时把层置为 active（可暂停，不锁存） |
| 指令落地循环 | 柱推进 `columnAdvance`、后方汇兵 `funnelScore`、原地筑垒 `INVEST_SCORE`、前线扩张 `expandScore`、退守 `guardScore` |

### 第二层：侦察—记忆—突袭（本轮）

| 位置 | 内容 |
| ---- | ---- |
| `fogBeliefTargets()` | 信念场：从己方皇冠做 BFS（山脉挡路，其余按可通行处理），取最远 70% 距离带中相隔 ≥3 格的 2 个锚点 |
| `fogAim` | 无记忆皇冠时改用信念锚点的距离场作目标场（`fogCfg.scout` 只驱动柱，`fogCfg.belief` 接管整个目标场） |
| `fogRaidUpdate()` | gather→raid 状态机：大堆先按住蓄兵，达到 `raidMass` 或 `raidRatio` 份额后出击；兵力跌破 `raidAbort` 份额退回蓄兵；主城受威胁立即暂停 |
| 主城布局 | `fogCfg.spread` 拒绝在已有皇冠 `spread` 步以内建新主城（输局回放里 2~3 座主城被同一支部队连锁吃掉） |
| 主城上限 | `fogCfg.homes` 抬高迷雾格的主城数量上限 |
| 房间门控 | `fogCfg.maze` 默认关：走廊图整层不介入（迷宫格 15/15/2、25/0/7 与基线逐局一致） |
| 威胁阈值 | 沼泽在迷雾中始终可见，因此地图构成可提前判定：沼泽占比 ≥55% 的群岛图使用 `aimLeadSwamp`（80）而不是 `aimLead`（60） |

- `fogRequired()`：迷雾格无法定价，于是“到目标剩余步数 × `guess`”作为保底预备队，步数封顶 8。柱只有付得起 `required + reserve` 才推进。
- `fogAim` 的解锁条件来自实测：`aimLead` 太紧会放过先手（60 → 100 时 Relay 四格胜数 79 → 69）；太松会在群岛格把兵力倒进敌方前线，所以群岛单独用 80。
- 侦察/信念/突袭/主城布局四个开关在本轮实测中都是**负收益或噪声**，默认关闭，逐项数据见“被否决的变体”。真正带来净收益的是“更早开始瞄准（Tick 60 而不是更晚）+ 一般图 60%、群岛图 80% 的分档 + 走廊图整层退出”。

## 开关

| 变量 | 默认 | 含义 |
| ---- | ---- | ---- |
| `BOT3_FOG` | **关** | `1` 打开整个迷雾单线层；默认关闭，默认路径与 round-2 基线逐局一致（2048 局 flips 全 0） |
| `BOT3_FOG_TURN` | `60` | 层最早启用的 Tick |
| `BOT3_FOG_GUESS` | `8` | 每剩余步的保底预备队 |
| `BOT3_FOG_FLOOR` | `0` | 柱启用所需的军力倍数下限（`army >= enemyArmy * floor`） |
| `BOT3_FOG_BOARD` | `800` | 层启用的最大格数（大图迷雾档自动退出） |
| `BOT3_FOG_COLUMN` | 开 | 柱状推进 |
| `BOT3_FOG_AIM` | 开 | 无记忆皇冠时把目标场回退到可见前线 |
| `BOT3_FOG_AIM_LEAD` | `60` | 一般地图前线瞄准所需的军力百分比 |
| `BOT3_FOG_SWAMP_LEAD` | `80` | 沼泽占比 ≥ `SWAMP_SHARE` 的地图（群岛）使用的军力百分比 |
| `BOT3_FOG_SWAMP_SHARE` | `0.55` | 判定“群岛型”地图的沼泽占比阈值 |
| `BOT3_FOG_MAZE` | **关** | `1` 允许层进入走廊图；默认关闭，走廊图完全交给迷宫层 |
| `BOT3_FOG_SCOUT` | 关 | 信念场只驱动柱（实测 −6pp，见下） |
| `BOT3_FOG_BELIEF` | 关 | 信念场接管整个目标场（实测 −4pp） |
| `BOT3_FOG_RAID` | 关 | gather→raid 蓄兵突袭状态机（实测 −29pp） |
| `BOT3_FOG_RAID_MASS` | `240` | 出击所需的最少兵力 |
| `BOT3_FOG_RAID_RATIO` | `0.6` | 出击所需的机动兵力份额 |
| `BOT3_FOG_RAID_ABORT` | `0.35` | 兵力跌破该份额退回蓄兵 |
| `BOT3_FOG_SCOUT_RATIO` | `0.7` | 信念场取最远距离带的比例 |
| `BOT3_FOG_SCOUT_COUNT` | `2` | 信念锚点数量 |
| `BOT3_FOG_SCOUT_SPREAD` | `3` | 信念锚点之间的最小曼哈顿间距 |
| `BOT3_FOG_SPREAD` | `0` | 新主城与最近主城的最小间距（0 = 关闭） |
| `BOT3_FOG_HOMES` | `0` | 迷雾格主城数量下限（0 = 关闭） |
| `BOT3_FOG_INVEST` | 关 | 允许在前线附近筑垒（实测负收益） |
| `BOT3_FOG_FUNNEL` | 关 | 后方汇兵进柱（实测全负） |
| `BOT3_FOG_EXPAND` | 关 | 柱优先吃中立格扩张 |
| `BOT3_FOG_GUARD` | 关 | 柱无目标时原地驻守 |

## 评测结果（16 种子，与 round-2 基线逐局配对）

迷雾单线筛查（4 对手 × 4 地图 × 16 种子 × 2 座位 = 512 局）：

```sh
BOT3_FOG=1 SEEDS=... OPPONENTS=apex,anti,v2,relay MODES=010 MAPS=random,maze,archipelago,mediterranean \
  node scripts/evaluate-bot3.cjs > /tmp/fog.jsonl
node scripts/compare-bot3-baseline.cjs /tmp/fog.jsonl data/scratch/round2-baseline.jsonl
```

### 留出验证（种子 17–32）

记录的 round-2 基线只覆盖种子 1–16，所以用 `BOT3_FOG=0`（与 round-2 逐局一致）在种子 17–32 上现录基线，再与 `BOT3_FOG=1` 配对：

| 配置 | 迷雾单线 512 局 | 基线 | Δwin | 低于基线的格 |
| ---- | ---: | ---: | ---: | ---- |
| `SWAMP_LEAD=90` | 357（69.7%） | 325（63.5%） | +6.3pp | 无 |
| `SWAMP_LEAD=100` | 359（70.1%） | 325（63.5%） | +6.6pp | 无 |
| `SWAMP_LEAD=80`（默认） | 354（69.1%） | 325（63.5%） | +5.7pp | Apex/群岛 −1、Bot(2.0)/群岛 −1 |

收益来自随机与地中海（Anti/地中海 +21.9pp、Anti/随机 +21.9pp、Apex/随机 +15.6pp、Bot(2.0)/随机 +12.5pp），Relay 四格 59 → 64 胜。群岛格的阈值对单局翻转很敏感（80 在 1–16 上零退化、在 17–32 上两格各 −1；100 反之；90 在 1–16 上 Anti/群岛 −2）。当前把 80 作为“记录矩阵零退化”的默认值；若要把层默认打开，建议先改成 100（留出集零退化）或干脆让群岛格整层退出（构造上零退化，代价是 Relay/群岛回到 50%）。

## 第三轮组合筛查：防线预备队不能整层放大

组合开启（`BOT3_MULTI=1 BOT3_FOG=1`）后，两个 -1 局退化格都是“原本快胜被柱拖成超时/失败”：

| 格 | round-2 | 组合 | 差异局 |
| --- | --- | --- | --- |
| `apex/archipelago/fog` | 24/5/3 | 23/5/4 | seed 2 seat 1 胜(234) → 超时；seed 10 seat 1 胜(279) → 负(891) |
| `v2/maze/fog` | 25/0/7 | 24/2/6 | seed 1/9/11 seat 1 胜(131/320/710) → 超时；seed 5/6 seat 0 超时 → 负 |

`BOT3_FOG_COLUMN=0` 把两格都还原到 round-2，但会把地中海/随机格的增益一起丢掉，所以不能整层关。
按“未知路线的预备队”整层放大 `GUESS` 是唯一有效的单旋钮，但收益和代价一样大：

| `BOT3_FOG_GUESS` | 迷雾单线（1024 局）Δ胜 vs round-2 | 仍低于 round-2 的格 |
| --- | ---: | --- |
| 8（默认） | +81 | `apex/archipelago` 23 vs 24、`v2/maze` 24 vs 25 |
| 16 | 修好 `v2/maze` 的 3 局胜局 | `apex/archipelago` 的 seed 2 反而变负(759) |
| 20 | +35 | `apex/archipelago` 23 vs 24、`relay/mediterranean` 14 vs 15、`relay/random` 13 vs 15 |
| 22 | +27 | `anti/archipelago` 19 vs 21、`apex/archipelago` 23 vs 24、`relay/random` 13 vs 15 |
| 24 | +10 | `anti/random` 15 vs 17、`relay/archipelago` 15 vs 16、`relay/random` 13 vs 15 |

结论：柱是否该接管是**局面问题**，不是预备队大小的问题。同一个 `GUESS` 在 anti/apex/v2/relay 的迷雾格上方向相反，
整层放大只是把一处单局翻转换成另一处。因此默认仍为 `GUESS=8`，本轮不为“组合零退化”改动迷雾层；
要真正收敛需要按局面特征（谁在收紧、皇冠是否已知、时间压力）回退柱，而不是权重微调。

## 未解决

- **Relay 迷雾单线仍达不到 65%**（当前 46.9%~62.5%，合计 55.5%）。Relay 的迷雾打法和我们同源，`round2` 基线里胜负由出生点几何决定（同一张图两个座位互换后逐局对称：15/15/2、16/16/0、15/15/2、15/15/2）。要每格 21/32 必须系统性强于同源克隆，当前层在“先手瞄准 + 梯次阈值”上拿到了 +7.8pp，但还差 3~5 局/格。
- 信念场的精度按地图分层：随机图 14/16 落在最远 3 格内、迷宫 16/16 最远格、地中海 10/16 前 5 格、群岛基本无效（出生点最大化的是“岛屿中心距离”，不是图距离）。因此“主动出击信念锚点”只在随机/迷宫上有信息优势，而这两个图的收益又不足以抵消离家的防守损失（`SCOUT` −6pp）。
- 真正的下一步是**防守换收益**：输局回放里 2~3 座主城被同一支部队连锁吃掉（主城间距 1~3 步，守军 5~30），而多建主城/分散主城在本轮的评分体系下都会分流兵力。需要把“主城是必须守住的资产”写进评分（例如按敌方最大可见堆大小给主城定驻军下限），而不是只调主城位置。
- 迷雾单线的 128 局筛选中，±3 局（±9pp）属于噪声；本轮结论都建立在 512 局/2048 局上，所有“单格大涨”的配置都复核过完整矩阵才写进结论。群岛阈值（`SWAMP_LEAD`）在两组种子上无法同时做到零退化，说明那一格的 +2~+5 胜里仍有一局是混沌翻转，而不是稳定的信息优势。
- 只有 16 个种子有记录基线，本轮的所有调参都在这 16 个种子上完成；17–32 的留出验证只是方向性确认（+5.7pp），不能替代 32 种子的完整验收。
