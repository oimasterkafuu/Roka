# Roka

Roka 是一个实时方格领土战争游戏（generals.io 类），使用 TypeScript + Fastify + Socket.IO 实现。

## 运行

```shell
pnpm install
pnpm run dev
```

或构建后运行：

```shell
pnpm run build
pnpm run start
```

其他常用命令：`pnpm run lint`、`pnpm run format`、`pnpm run test:bot`（bot 集成测试：用临时数据目录启动服务器，接入两个 `bot-template/random-patch-bot` 自动开局对局；dist 缺失时会自动构建）、`pnpm run test:server-bot`（服务端托管策略 Bot 冒烟测试：超管 API 启动 simple-strategy-bot 与 random-patch-bot 对局，校验房长保留、自动准备、实际走子与停止 API）、`pnpm run test:lobby-guards`（开局/换绑守卫回归：全员同队拒绝开局、同名人类不抢 bot 席位、断线重连恢复）。

启动后访问 `http://localhost:23333/` 并注册账号。

## 游戏规则

与旧版 / generals.io 的主要差异：

- **Tick**：1 Tick = 0.5 秒，速度 speed 0.5~4 只缩放 Tick 间隔。
- **生产**：主城（crown）每 Tick +1；普通地块与指挥所（city）每 50 Tick +1（仅正常状态）；沼泽、中立格不生产。
- **爆发期**：第 26~50 Tick 为全局爆发期，正常普通领土每 Tick 额外 +1；客户端表现为地图最外圈红色边缘（逐渐减弱）。
- **推兵三种模式**：普通 WASD 全兵（只留 1 兵看守，其余全部推出）；Z 半兵（一次性，按智能分兵理论推出减半取整，执行后失效）；Shift+WASD 智能分兵（保留 = 其他三方向非己方相邻格「兵力-1」之和 + 1，目标方向不参与计算；不消耗 Z）。优先级 Shift > Z > 普通。
- **攻击判定**：攻击兵力严格大于防守兵力才占领；未严格大于（含相等）时进攻失败但双方互损——进攻方损失全部推出兵力，防守方等量减兵（最低到 0，归属/建筑不变）。占领后防守兵力全灭，新兵力 = 攻击兵力 − 防守兵力（占领有损耗）；占领建筑 = 摧毁建筑（变为普通地）。占领敌方最后一座主城 → 该玩家出局，其剩余领土不转移、不折半，全部沦为孤军并逐渐衰减消亡。
- **光标**：WASD 后光标总是移动到相邻非山脉格，即使该次推兵无效（兵力 ≤ 1、选中非己方格等）——无效推兵不入队、不显示箭头，光标保持可移动。
- **建造**：X 建指挥所（己方正常普通地块、兵力 ≥ 50、已连通己方主城/指挥所，消耗 50）；C 升级主城（己方正常状态的指挥所、兵力 ≥ 50，消耗 50，立即获得每 Tick +1 生产与锚点资格）；在普通地块上按 C = 连续两步（先建指挥所、下一 Tick 升级主城），角标同时显示指挥所与皇冠。建造与推兵共用同一队列（每 Tick 每玩家最多执行一条队列操作）；入队只校验地形，归属/兵力/连通在执行时校验，不满足则自动跳过并继续执行后续操作。沼泽/山脉禁止建筑。
- **连通与孤军**：己方格经连续己方格（普通地或己方沼泽）四方向连通到己方任意主城/指挥所 = 正常领土，否则断链为孤军。断链瞬间兵力减半（⌊n/2⌋，1 兵保持为 1）；孤军不可选中/推兵/建造/生产、无爆发加成；断链后前 5 回合（10 Tick）为宽限期，只快速闪烁不衰减，第 6 回合起每回合（每 2 Tick）衰减 max(1, ⌈当前兵力×5%⌉)，归零变中立；孤军连通组件重新接回己方主城/指挥所时立即恢复正常且每格兵力 ×2。孤军格在客户端闪烁（宽限期快速闪烁，衰减期常速闪烁），闪烁由全局时钟驱动，不受本地操作影响。
- **空格**：跳转选中到曼哈顿距离最近的己方主城（距离相同取建立较早者）；镜头仅在目标不在当前视野内时才拖动居中，已在视野内则保持不动。
- **胜负**：最后主城决胜制——失去所有主城即出局，存活至最后的队伍获胜。
- **掉线宽限期**：对局中网络断开后有 10 秒宽限期（1 倍速 = 20 Tick），期间不判挂机、不投降，刷新页面/重连即可恢复对局（服务端自动补发全量状态）；超过宽限期以「挂机」原因自动投降并转为观战。主动退出（返回房间 / 离开）不变，仍立即投降。
- **视野**：无战争迷雾，全图始终可见；城市（指挥所）不再由地图预置，只能由玩家建造。
- **地形**：山脉不可通行/占领；沼泽可占领可存兵，但永不生产、不可建筑、参与连通。

## 平台功能

- 用户系统（注册 / 登录）；首个注册用户自动成为超级管理员（唯一，不可剥夺、不可封禁），可在后台管理页授予/撤销其他用户的管理员权限。
- 后台管理页 `/admin`（仅管理员可见入口）：用户列表（rating、注册/最后在线时间、角色、封禁状态），支持按时长封禁（1 小时/1 天/7 天/自定义/永久）与解封；被封禁用户无法登录且已登录的连接会被立即踢下线，封禁到期自动解除；管理员之间不能互相封禁，超级管理员不受限制。超级管理员另有「策略 Bot」分区：指定已注册用户名与房间号即可在服务器进程内启动 `bot-template/simple-strategy-bot`（内存临时令牌鉴权，跳过验证码），Bot 自动进房/准备、对局结束后自动重新准备、可随时手动停止；托管 Bot 进房不当房主（房主保留给后续进房的人类用户或第三方 Bot）、豁免房间心跳踢出、不参与单会话顶号互斥。
- 策略 Bot 模板 `bot-template/simple-strategy-bot`：具备威胁推演/集结防御/风险感知路径打击/积极皇冠建设/多源兵力汇集的综合策略（`strategy.js` 管线编排 + `bot/` 纯函数模块），可独立运行（与 random-patch-bot 相同的 CLI 用法），其 `strategy.js` 同时被服务端托管运行复用。
- FFA 与组队模式，统一 Rating（不区分 1v1 / FFA）；Codeforces 风格段位名字颜色。新手显示分仿 Codeforces 从 0 起步（按 1200 / 2^对局数 的 delta 逼近真实分），内部结算仍按 1200 初始分。
- 首页三栏布局：左侧个人信息、房间列表（状态列区分「游戏中 / 人数不足 / 准备进度」）与回放列表（自己参与的对局浅黄高亮）；中间「动态」feed；右侧公告（仅管理员可编辑，与动态同一条管线，支持 Markdown 与服务端渲染的 LaTeX）、Rating 排行榜（前 10，Unrated 不参与）与「刚刚在线」列表（最近下线的前 8 位用户及下线相对时间）。
- 顶栏实时展示当前在线人数：覆盖网站所有页面的 socket 连接，同一用户多个标签页只计一次，bot 令牌连接不计入；通过 `home_online` socket 失效通知（2 秒节流）驱动首页刷新，数据来自 `GET /api/online`。
- 回放可下载为原始 `.rpl` 操作流文件（仅几百字节，只有服务端能解码）；观看页直接下发 gzip 压缩后的转码二进制（服务端按回放 id 落盘缓存，首次观看后无需再重建整场对局），加载期间显示下载进度；首页回放面板支持「上传并查看回放」——POST 给服务器转码后播放，版本过旧或损坏会弹出「不兼容」提示，服务端库存的不兼容回放会被自动删除。
- 「动态」：类似推特的 feed，支持点赞、评论、编辑与删除（管理员可管理全部），支持 Markdown 与服务端渲染的 LaTeX；发布有 30 秒冷却；URL 带页码可分享翻页位置。
- 个人主页 `/u/<用户名>`：Rating 历史曲线、注册天数、其动态与参与的对局回放。
- 房间内支持观战；非观战玩家中「我准备好了」超过半数（向下取整）时自动开始。组队模式下若所有参赛者处于同一队伍，服务端拒绝开局并在房间消息中提示调整队伍（否则对局一开始就只有一支存活队伍，会立即终局）。
- **房间心跳检测**：房间准备阶段客户端每 30 秒上报一次心跳；超过 600 秒（10 分钟）无心跳的成员被服务端自动移出房间并跳回首页。对局进行中不检查心跳（对局断线仍走 10 秒宽限期）；`ROKA_BOT_TOKENS` 鉴权的 bot 连接豁免。
- **浏览器通知**：登录后首次访问首页或房间页时，若浏览器通知权限尚未决定，会先弹解释窗说明用途（新玩家进房、游戏开始、有人上线或建房），由按钮手势申请权限；拒绝后不再打扰，解释窗每个浏览器最多弹一次。页面在后台时，房间内新玩家加入、游戏开始、首页有人上线或创建新房间都会弹系统通知；同一用户多个后台标签页通过 Notification `tag` 与 localStorage 时间戳互斥保证只弹一次。浏览器不支持 Notification 时静默跳过。
- 实时聊天框跨房间同步。
- 教程分文字版（`/tutorial`）与互动版（`/tutorial/interactive`）两步。
